# RideEase Android Client (Planned)

This directory contains the Gradle build scaffolding for the native Android client applications (Rider & Driver Partner).

## Development Status
- **Current Status:** Planned / Design Specification phase.
- **Active Production Application:** The primary, fully implemented RideEase application is the multi-port Spring Boot + Thymeleaf web platform located in `backend/`, serving:
  - Port 8080: Rider Web Portal
  - Port 8081: Driver Partner Web Terminal
  - Port 8082: Fleet Administrator Dashboard
